Create an empty "Home Videos and Photos" library with one folder for this (turn off chapter and trickplay image extraction). The sync task writes its .strm files into that folder, so Jellyfin needs write access to it.
Internet Archive items to take commercials from. The identifier is the part after /details/ in the item's address, e.g. archive.org/details/identifier. Include and exclude take comma-separated file name patterns such as *1983*; leave them empty to use every video in the item.
